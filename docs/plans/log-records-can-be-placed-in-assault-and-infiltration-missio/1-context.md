## Conventions that constrain this

- **Never widen the ground player into `PlayerBase`** — the task body explicitly calls this out as a much larger change this epic isn't touching. The fix is entirely on the detection side.
- **Design-unit coordinates apply to waves/spawns, not to this static placement mechanism** — but this task still computes the assault position from a 640×360 design offset for consistency and documents the arithmetic in the scene, since nothing else in the file explains where a hand-placed number came from.
- **Never route through `WaveManager` for a pickup** — confirmed above to silently corrupt `ScoreTracker`'s wave-clear/escape bookkeeping.
- **Signal/logging conventions**: no new signals are declared here that need arity discipline; `PickupState` needs no per-frame logging.
- **`user://` save sandbox discipline** (`tests/README.md`): any test touching the new `PickupState` autoload must go through `SaveSandbox`, extended with the new path.
- Building `LoreLogPickup` itself is explicitly **out of scope** — that class belongs to the stuck sibling task. This task only builds the infrastructure it will need.
